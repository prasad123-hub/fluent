# Scenario authoring guide

Scenarios are **data**, not prompts hard-coded in the agent. They live in
`apps/web/prisma/seed-data/<theme>.ts` (one file per theme), are validated by
`prisma/seed-data/seed-data.test.ts` against the shared schema
(`packages/shared/schemas/scenario.schema.json`), and are upserted by `pnpm db:seed`.
Custom scenarios created in the app go through the same schema (`src/lib/schemas.ts`).

## Shape (all fields required unless marked)

| Field                     | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                      | kebab-case, prefixed by theme (`office-`, `interview-`, `pron-` …). Stable forever — reports link to it.                                                                                                                                                                                                                                                                                                                                |
| `title`, `description`    | Title ≤ 60 chars; description is one or two concrete sentences (who, where, what).                                                                                                                                                                                                                                                                                                                                                      |
| `difficulty`              | `A2` \| `B1` \| `B2` \| `C1`. The agent adds vocabulary/sentence-length rules per level.                                                                                                                                                                                                                                                                                                                                                |
| `mode`                    | `roleplay` \| `discussion` \| `interview` \| `drill` \| `free_talk`. `interview` enables the interview rubric; `drill` enables instant scoring.                                                                                                                                                                                                                                                                                         |
| `agentPersona`            | `{ name, role, personality, accent }`. `accent` is a hint for voice selection ("Indian English", "British", …).                                                                                                                                                                                                                                                                                                                         |
| `agentOpeningLine`        | The exact first spoken line. Sent with `session.say()` (no LLM round-trip) so it lands within ~2 s.                                                                                                                                                                                                                                                                                                                                     |
| `learnerGoal`             | One sentence shown on the Practice page.                                                                                                                                                                                                                                                                                                                                                                                                |
| `successCriteria[]`       | 3–4 observable statements. The analysis grades each ✓/✗ with evidence.                                                                                                                                                                                                                                                                                                                                                                  |
| `keyVocabulary[]`         | 5–10 words/phrases shown in the sidebar and used for vocabulary recommendations.                                                                                                                                                                                                                                                                                                                                                        |
| `usefulPhrases[]`         | 4–5 full sentences; also used by `give_hint`.                                                                                                                                                                                                                                                                                                                                                                                           |
| `commonMistakesToWatch[]` | `"wrong (→ right)"` lines typical for Indian English speakers; injected into the agent prompt.                                                                                                                                                                                                                                                                                                                                          |
| `suggestedDurationMin`    | 2–30.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `systemPromptTemplate`    | 60–130 words describing the scene, the character's facts (prices, names, dates), and how to run the conversation. Placeholders: `{{persona.name}}`, `{{persona.role}}`, `{{persona.personality}}`, `{{learner.name}}`, `{{difficulty}}`, `{{duration}}`. End with `${PROMPT_RULES}`. Coaching-mode, difficulty and learner-profile blocks are appended by the agent (`apps/agent/src/fluent_agent/prompt.py`) — do **not** repeat them. |
| `characters[]` (optional) | For panels / group discussions: `{ name, role, personality, voice }` where `voice` is a preset key (`priya`, `arjun`, `katie`, `oliver`, `maya`, `sam`). The agent calls `switch_persona` to change voice.                                                                                                                                                                                                                              |
| `tags[]` (optional)       | `popular`, `beginner-friendly`, `drill`, `ielts`, … used for filters.                                                                                                                                                                                                                                                                                                                                                                   |

## Writing tips

- Give the character **concrete facts** (floor price, slot times, product names) so the role-play is consistent across turns and across simulations.
- Keep it local and realistic (Pune, Bengaluru, IPL, Ganeshotsav, appraisal cycles) without stereotypes.
- For drills, put the actual word lists / sentences / passage **inside the template** and tell the agent to present one item at a time and call `score_drill_attempt` after each attempt.
- Keep the opening line short and natural; it is spoken verbatim.

## Adding a scenario

1. Append to the theme file (or add a new theme in `themes.ts` **and** `index.ts`).
2. `pnpm --filter @fluent/web test` (schema + counts) → `pnpm db:seed` (idempotent upsert).
3. Optionally add a simulation scenario in `apps/agent/scenarios/*.yaml` that exercises it.
